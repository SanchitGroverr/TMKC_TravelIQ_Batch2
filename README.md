# TMKC_TravelIQ_Batch2
Mini Hackathon
SMART TRAVEL AND ATTENDANCE PLANNER
Problem Statement:University students frequently face a complex logistical challenge when planning travel home for semester breaks or long weekends: coordinating multi-modal transit options—including flights, trains, state buses, and university shuttles—while avoiding academic detainment due to falling below minimum attendance thresholds (e.g., 75%). Currently, no lightweight, efficient offline system exists to cross-reference a student's live academic standing with real-time multi-modal transit seat availability and fare sorting prior to booking.
